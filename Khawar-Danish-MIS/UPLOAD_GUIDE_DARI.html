آپلود خاور دانش به GitHub

چون حساب دارید، فقط مخزن را بسازید و نسخهٔ پاک را داخل آن بگذارید.

۱. پوشهٔ درست را انتخاب کنید

فایل Khawar-Danish-MIS-GitHub.zip را Extract کنید و پوشهٔ Khawar-Danish-MIS را باز کنید. داخل آن README.md و پوشه‌های app و public دیده می‌شود. فقط همین محتویات آماده را آپلود کنید.

پوشهٔ نصب C:\Khawar-Danish و بکاپ‌ها یا دیتای واقعی مرکز را به GitHub ندهید. ZIP را به‌عنوان یک فایل کد آپلود نکنید؛ محتویاتش باید باز شود.

۲. مخزن بسازید

  1. با حساب خود github.com/new را باز کنید.
  2. نام: Khawar-Danish-MIS.
  3. برای آغاز Private؛ اگر می‌خواهید کد برای همه دیده شود Public.
  4. README، .gitignore و License خودکار اضافه نکنید؛ داخل بسته موجودند.
  5. Create repository را بزنید.

۳. فایل‌ها را آپلود کنید

  1. در صفحهٔ مخزن خالی روی uploading an existing file بزنید؛ در مخزن دارای فایل، Add file → Upload files.
  2. محتویات داخل پوشهٔ Khawar-Danish-MIS را انتخاب و به صفحه بکشید. پوشهٔ بیرونی را داخل مخزن تودرتو نکنید؛ README.md باید در ریشه باشد.
  3. پیام Initial source upload را بنویسید و ثبت تغییرات را تأیید کنید.

اگر از ۱۰۰ فایل بیشتر شد، دو نوبت آپلود کنید. فایل‌های نقطه‌دار مثل .gitignore، .htaccess و پوشهٔ .github را هم حفظ کنید.

۴. نتیجه را بررسی کنید

در صفحهٔ اصلی، README نمایش داده شود؛ app و public موجود باشند. config/config.php، فایل ZIP بکاپ، دیتابیس یا عکس اشخاص نباید در مخزن باشند. در Actions نتیجهٔ PHP checks را ببینید.

این بسته فایل نمونهٔ config/config.example.php دارد؛ رمز واقعی شما داخل آن نیست. .gitignore مانع آپلود دستیِ فایل اشتباه در مرورگر نمی‌شود.

۵. کد با اجرای آنلاین فرق دارد

GitHub کد را نگه می‌دارد. GitHub Pages فقط سایت استاتیک را میزبانی می‌کند و PHP/MySQL این سیستم را اجرا نمی‌کند. نصب محلی شما با این آپلود تغییر نمی‌کند.
